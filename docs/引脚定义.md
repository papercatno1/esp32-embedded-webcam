# 引脚定义

来源：微雪官方产品图（用户提供，见 [img/引脚分布-官方.png](img/引脚分布-官方.png)）+ 固件二进制分析。

> ⚠️ 先说清楚一件事：**这张图是"对外排针"的定义**。
> 板上固定外设（2 寸屏、OV5640、QMI8658、TF 卡、电池检测）全部走**内部连线**，不出现在排针上，
> 所以这张图解决不了"屏和摄像头接在哪些 GPIO"——那部分见第 3 节。

## 1. 排针定义（按丝印编号）

### 左侧排针（丝印 28 → 15，从上到下）

| 编号 | 丝印 | 说明 |
| --- | --- | --- |
| 28 | GPIO2 | 通用 IO（启动时需注意电平，strapping 相关） |
| 27 | GPIO4 | 通用 IO |
| 26 | GPIO6 | 通用 IO（**SPI Flash 引脚，慎用**） |
| 25 | GPIO16 | 通用 IO |
| 24 | GPIO17 | 通用 IO |
| 23 | GPIO18 | 通用 IO |
| 22 | GPIO21 | 通用 IO |
| 21 | GPIO8 | 通用 IO（strapping） |
| 20 | GPIO7 | 通用 IO |
| 19 | GPIO10 | 通用 IO |
| 18 | GPIO20 | 通用 IO（USB D+ / D−，**插着 USB 时别占**） |
| 17 | GPIO19 | 通用 IO（USB D− / D+，同上） |
| 16 | GND | 地 |
| 15 | 5V | 5V 输入/输出（USB 供电时可用） |

### 右侧排针（丝印 1 → 14，从上到下）

| 编号 | 丝印 | 说明 |
| --- | --- | --- |
| 1 | 3V3 | 3.3V 电源 |
| 2 | GND | 地 |
| 3 | TXD | UART0 TX（一般 GPIO43） |
| 4 | RXD | UART0 RX（一般 GPIO44） |
| 5 | GPIO47 | 通用 IO |
| 6 | GPIO48 | 通用 IO（板载 RGB LED 常用脚，待实测） |
| 7 | GPIO15 | 通用 IO |
| 8 | GPIO13 | 通用 IO |
| 9 | GPIO11 | 通用 IO |
| 10 | GPIO12 | 通用 IO |
| 11 | GPIO14 | 通用 IO |
| 12 | GPIO9 | 通用 IO |
| 13 | GND | 地 |
| 14 | VBAT | 电池电压（接电池时供电/测压） |

### 按功能归类

| 用途 | 引脚 |
| --- | --- |
| 电源 | `3V3`(1)、`5V`(15)、`VBAT`(14)、`GND`(2/13/16) |
| 串口 0 | `TXD`(3)、`RXD`(4) |
| 可用 IO（14 个） | GPIO2 / 4 / 6 / 16 / 17 / 18 / 21 / 8 / 7 / 10 / 20 / 19 / 47 / 48 / 15 / 13 / 11 / 12 / 14 / 9 |
| 板载按键 | `BOOT` = **GPIO0**（图上标注）、`RST` = EN |

> 注意：`GPIO6/7/8/9/10/11` 在 ESP32-S3 上默认是 SPI Flash 用脚，多数开发板没有引出全部；
> 这块板把它们引出来了，**用之前必须确认没和 Flash 冲突**（这块板的 Flash 走的是专用引脚组，但这几个仍要谨慎）。

## 2. 板上按键与指示灯

| 器件 | 引脚 | 用途 |
| --- | --- | --- |
| BOOT 键 | GPIO0（拉低进下载模式） | 复位时长按 → 进 bootloader；也可作普通按键 |
| RST 键 | EN | 硬复位 |
| 蓝色 LED | 电源指示 | 上电常亮 |
| 红色 LED | 运行/无线状态 | 出厂 demo 常亮 |

## 3. 内部外设引脚（待补）

这三类还没拿到权威引脚表：

| 外设 | 需要的信号 | 现状 |
| --- | --- | --- |
| 2 寸屏 ST7789（SPI） | SCLK / MOSI / CS / DC / RST / BL（背光 PWM） | **驱动 IC 已确认是 ST7789**（见第 4 节），引脚待补 |
| OV5640 摄像头（DVP） | XCLK / PCLK / VSYNC / HREF / D0–D7 / SIOD / SIOC / PWDN / RESET | 待补 |
| QMI8658 IMU（I2C） | SDA / SCL / INT | 待补 |
| TF 卡（SDMMC 4 线） | CLK / CMD / D0–D3 | 待补 |
| 电池检测（ADC） | 分压后接某 ADC 通道 | 待补 |

**补齐办法**（任选其一）：

1. 官方 wiki 的 Arduino 页面有完整引脚表 → 打开 <https://www.waveshare.com/wiki/ESP32-S3-LCD-2> 截图即可（我这边 DNS 打不开该站）。
2. 装好工具链后，用"逐脚试探"的测试固件反推（慢，且要小心别把屏的背光脚当普通 IO 拉高）。
3. 从官方 demo 源码里抄（如果拿得到仓库）。

## 4. 屏驱动 IC 已确认：ST7789

不是猜的。在整片固件备份里按 ST7789 初始化序列的字节特征扫描，命中一整套连贯的命令表（`0x29D80` 起）：

```
0029d80  EC B2 02 42 0C BC 02 42 14 C5 02 42 00 01 11 0B
0029d90  0C 78 00 07 3A 55 07 36 00 09 B0 02 00 F0 09 B2
0029da0  05 0C 0C 00 33 33 07 B7 35 07 BB 19 07 C0 2C 07
0029db0  C2 01 07 C3 12 07 C4 20 07 C6 0F 08 D0 A4 A1 09
0029dc0  E0 0E F0 09 13 12 12 2B 3C 44 4B 1B 18 17 1D 21
0029dd0  09 E1 0E F0 09 13 0C 0D 27 3B 44 4D 0B 17 17 1D
0029de0  21 01 13 0B 0C 0A 00 01 29 0B 00 00 00 00 00 00
```

解析出的命令序列（ST7789 的教科书式初始化）：

| 命令 | 参数 | 含义 |
| --- | --- | --- |
| `0x11` | — | SLPOUT 退出睡眠 |
| `0x3A 55` | 0x55 | COLMOD = 16 bit/pixel（RGB565） |
| `0x36 00` | 0x00 | MADCTL 扫描方向 |
| `0xB2 05 0C 0C 00 33 33` | — | PORCTRL 门廊设置 |
| `0xB7 35` | — | GCTRL 栅极电压 |
| `0xBB 19` | — | VCOMS |
| `0xC0 2C` `0xC2 01` `0xC3 12` `0xC4 20` `0xC6 0F` | — | 电源控制一组 |
| `0xD0 A4 A1` | — | PVGAMCTRL |
| `0xE0` + 14 字节 / `0xE1` + 14 字节 | — | 正/负 Gamma |
| `0x13` | — | NORON 普通显示模式 |
| `0x29` | — | DISPON 开显示 |

结论：**240×320、16 位色、SPI 接口、ST7789 驱动**。
M1 点屏直接用 `Arduino_GFX` 的 `Arduino_ST7789` 或 `LovyanGFX` 的 `Panel_ST7789` 类即可，只差引脚号。
