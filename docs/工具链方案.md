## 二、三条路线，怎么选

| | **A. PlatformIO（推荐）** | B. Arduino CLI | C. ESP-IDF** |
| --- | --- | --- | --- |
| 形态 | VS Code 扩展 + `pio` 命令行 | 纯命令行 | 官方 SDK + `idf.py` |
| 上手速度 | 快 | 最快 | 慢 |
| 配置 | `platformio.ini` 一文件固化板型/分区/上传参数，随仓库走 | 命令行参数，易丢 | `sdkconfig` + CMake |
| 库生态 | 自动拉 Arduino 库（`esp32-camera`、`lvgl` 都是一条 `lib_deps`） | 同 Arduino | 官方组件（`esp_lcd`、`esp_camera`、`esp_lvgl_port`） |
| 底层控制 | 中（可随时切 `framework = espidf`） | 低 | 最高 |
| 体积 | 核心 ~1.5–2 GB（首次拉工具链） | ~1.5–2 GB | ~3 GB |
| 适合 | **本项目主路线** | 临时验证、CI | 后期做产品级、需要 DMA/LCD_CAM 精调 |

**结论：主用 A（PlatformIO + Arduino 框架），保留切 ESP-IDF 的口子。**

理由：
1. 出厂固件本身就是 Arduino-ESP32 3.1.1 编的，走 Arduino 生态**最贴近现成 demo 和社区例程**，点屏/拍照半天就能出东西。
2. 这个板子的资源（8 MB PSRAM + 16 MB Flash）足够 Arduino 框架跑 LVGL + 摄像头 + 图传。
3. `platformio.ini` 可以把"板型、Flash 布局、PSRAM 开关、USB CDC"全部写进仓库——符合"项目数据独立管理"的要求，换台电脑 clone 下来就能编。
4. 真要抠性能（双缓冲刷屏、DMA、LCD_CAM 并行接口）时，同一个工程把 `framework` 换成 `espidf` 即可，不用重搭。

### 安装清单（装 A）

| 步骤 | 动作 | 体积/耗时 |
| --- | --- | --- |
| 1 | VS Code 装扩展 `PlatformIO IDE` | ~200 MB |
| 2 | 首次建工程，PIO 自动拉 `platform-espressif32` + xtensa 工具链 | ~500 MB |
| 3 | Python 侧装 `platformio`（已有 venv 可直接 `pip install platformio`，便于我这边命令行驱动） | ~50 MB |
| 4 | 补 `esptool`/`openocd`（PIO 自带，无需另装） | 内置 |

工程关键配置（骨架，实测后再调）：

```ini
[env:esp32s3]
platform  = espressif32
board     = esp32-s3-devkitc-1      ; 16MB flash + 8MB PSRAM 的 S3 通用定义
framework = arduino
board_build.arduino.memory_type = qio_opi   ; PSRAM 走 OPI
board_build.flash_size  = 16MB
board_build.partitions  = partitions_16MB.csv
build_flags =
    -DBOARD_HAS_PSRAM
    -DARDUINO_USB_MODE=1            ; 与出厂固件一致：USB-Serial/JTAG
    -DARDUINO_USB_CDC_ON_BOOT=1     ; 串口走 CDC，COM16 直接看日志
    -DCORE_DEBUG_LEVEL=3
upload_speed = 921600
monitor_speed = 115200
```

> `ARDUINO_USB_MODE=1` + `CDC_ON_BOOT=1` 是从出厂固件的 FQBN 里抄来的
> （`USBMode=hwcdc,CDCOnBoot=cdc`），保证烧完还能用 `COM16` 直接看 `Serial` 输出。

## 三、功能开发地图

按"能先看到东西"的顺序排。每项都写清楚：**用什么库 / 依赖什么 / 难点在哪**。

### 3.1 显示（240×320 IPS）

| 层 | 方案 | 说明 |
| --- | --- | --- |
| 驱动 | `Arduino_GFX`（GFX Library for Arduino）或 `LovyanGFX` | 都是 SPI 屏，240×320，驱动 IC 待确认（大概率 ST7789，也可能是 ST7796/GC9A01 类） |
| UI | **LVGL 9.x** | `lib_deps = lvgl/lvgl@^9`；用 PSRAM 做双缓冲 240×320×2B ≈ 150 KB/帧 |
| 加速 | DMA（SPI DMA 通道） | `Arduino_GFX` 的 `Arduino_ESP32SPI` 支持 DMA 发送 |

**待确认**：LCD 驱动 IC 型号、背光 PWM 引脚、SPI 频率上限（官方 wiki 引脚表）。
**验证手段**：先刷一个"纯色→彩条→文字"的测试固件，能看清就算通。

### 3.2 摄像头（OV5640）

| 项 | 方案 |
| --- | --- |
| 库 | `esp32-camera`（`lib_deps = espressif/esp32-camera`） |
| 分辨率 | OV5640 支持到 2592×1944；实际用 **SVGA(800×600) / VGA(640×480)** 跑预览，UXGA 拍照 |
| 格式 | JPEG（OV5640 支持硬件 JPEG，最省带宽）或 RGB565 |
| 缓冲 | 必须放 PSRAM（`CAMERA_FB_IN_PSRAM`） |
| 自检 | `esp_camera_init()` 返回 `ESP_OK` = 接线正确；`ESP_ERR_NOT_FOUND` = SCCB 扫不到（地址 0x3C），多为 FPC 朝向反/没插到底 |

**这一步顺带把"摄像头到底接对没有"彻底定论。**

### 3.3 存储（TF 卡）

- `SD_MMC`（1-bit 或 4-bit），4 线速度高，需确认 CMD/CLK/D0-D3 引脚。
- 拍照存 `/photo/YYYYMMDD_HHMMSS.jpg`；录像可以先做"连拍 JPEG"。

### 3.4 传感器

| 传感器 | 接口 | 方案 |
| --- | --- | --- |
| QMI8658 六轴 IMU | I2C | `SensorLib`（Lewis He）或直接 I2C 读寄存器；出厂 demo 有 `qmi8658_task` 可参考现象 |
| 电池电压 | ADC1 + `analogReadMilliVolts()` | 出厂 demo 显示 3.87 V（USB 供电、无电池），说明走的是分压检测，需实测校准系数 |
| 芯片温度 | 内置温度传感器 | `temperatureRead()` |

### 3.5 无线

| 能力 | 方案 | 备注 |
| --- | --- | --- |
| Wi-Fi STA | `WiFi.h` | 连家里路由，拿 IP |
| 图传网页 | `esp_http_server` 或 `ESPAsyncWebServer` + MJPEG 流 | 浏览器 `<img src="/stream">` 直接看 |
| 配网 | `network_provisioning` / SmartConfig / AP 配置页 | 出厂固件走的是"屏幕上输 SSID 密码"，无触摸时改走手机配网 |
| BLE | `NimBLE-Arduino` | 手机 App 控制、传传感器数据 |
| OTA | `ArduinoOTA` / `esp_https_ota` | 有 Wi-Fi 后强烈建议先做，省得反复插线 |

### 3.6 调试

- **USB-JTAG 是内置的**（`USB\VID_303A&PID_1001&MI_02`），配合 OpenOCD + GDB 可单步调试、看变量、抓 HardFault 现场，**不需要额外买调试器**。
- 串口：`COM16` @115200，`Serial` 走 CDC，插上就能看日志。

## 四、里程碑（建议节奏）

| 阶段 | 内容 | 产出 | 估计 |
| --- | --- | --- | --- |

## 五之附：网页抓取工具（本机环境专用）

本机在跑 Mihomo TUN（fake-ip 模式），`www.waveshare.com` 这类域名被解析成 `198.18.0.x`（保留网段），
harness 的 `web_fetch` 出于 SSRF 防护会拒绝访问；但本机正常网络是通的。因此项目里带了个本地抓取脚本：

```powershell
.\.venv\Scripts\python.exe scripts\webget.py https://www.waveshare.com/wiki/ESP32-S3-LCD-2 --grep "GPIO|ST7789"
.\.venv\Scripts\python.exe scripts\webget.py URL -o page.html --raw
```

## 六、一句话总结

> **PlatformIO（Arduino 框架）起步，先跑通 M0→M2 这三步——blink、点屏、摄像头自检。**
> 摄像头自检那一步同时解决"到底接对没有"的问题；等方案定了再决定要不要下沉到 ESP-IDF。
