## 自检结果

- 文件长度 = 16,777,216 字节（正好 16 MB，无截断）。
- 偏移 `0x0` 起为 `e9 04 02 4f`（ESP 镜像魔数，即二级引导 bootloader）。
- 偏移 `0x8000` 分区表解析正常：`nvs / otadata / app0 / app1 / ffat / coredump`。
- 偏移 `0x10020` app 描述符正常：`arduino-lib-builder`、`Jan 6 2025`、IDF `v5.3.2`。
- `0x10000–0x310000`（app0）与先前单独 dump 的 `dump\app0.bin` **SHA256 完全一致** → 两次读取互相印证，备份有效。

## 恢复

```powershell
# 整片写回（会覆盖当前固件，先确认板子没在执行别的操作）
.\.venv\Scripts\python.exe -m esptool -p COM16 -b 921600 write-flash 0x0 dump\full_flash.bin
```

恢复后建议读回校验：

```powershell
.\.venv\Scripts\python.exe -m esptool -p COM16 -b 921600 read-flash 0x0 0x1000000 dump\verify.bin
(Get-FileHash dump\full_flash.bin -Algorithm SHA256).Hash
(Get-FileHash dump\verify.bin -Algorithm SHA256).Hash
```

## 备注

- 备份里包含 `ffat` 分区（`0x610000`，约 10 MB）——出厂演示用的字体/图片资源都在里面，恢复时一并还原。
- 这份备份是**唯一一份可回滚的出厂状态**，建议另存一份到别的磁盘/网盘，别只留 `E:\ESP32开发\dump`。
