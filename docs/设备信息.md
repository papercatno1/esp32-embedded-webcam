## 2. 照片判读要点

### 2.1 板子正面（`设备图片\板子正面照.jpg`）

- 蓝色 PCB，四角铜柱，上下各一排黄色排针（母座/镀金针），可引出 GPIO。
- 板载丝印：`ESP32-S3-…`、`240x…`、`3V3 / G / TX / RX / 47 / 48 / … / VBAT` 引脚标注（见 `docs\img\板载丝印-ESP32-S3.jpg`）。
- 左上角 **U.FL/IPEX 天线座**（橙圈）+ 板载 PCB 天线，可外接天线。
- 中部：**ESP32-S3R8 主控 QFN 芯片** + 独立的 **16MB SPI Flash**（丝印 `XTX`）。
- 右侧：**USB-C 口**、`BOOT` 与 `RST` 两个轻触按键。
- 中部偏右：**40pin LCD FPC 座**（0.5mm 间距，接 2 寸屏）与 **24pin 摄像头 FPC 座**（接 OV5640）。
- 左侧：**TF（microSD）卡座**；`BAT` 电池座。
- 整体装在透明收纳盒 + 防静电海绵里。

### 2.2 屏幕模块（`设备图片\板子屏幕与接口.jpg`）

- 一块裸 2 寸级 IPS 面板 + 长 FPC 排线 + 一小段带补强的接口段，装在独立透明盒内。
- 未插在板上（PCB 上 40pin FPC 座目前是空的），需要时手动插入并锁扣。

### 2.3 摄像头（`设备图片\摄像头照片.jpg`）

- 银色防静电袋，标签：`SKU: 29456` / `ESP32 OV5640 Camera【摄像头】` / `Made in China`（见 `docs\img\摄像头包装标签-OV5640.jpg`）。
- 摄像头本体带 24pin 0.5mm FPC 与补强板，配红色镜头座（可调焦），与板上 24pin 座匹配。

## 3. 上电实测（本机）

### 3.1 端口枚举

```
USB\VID_303A&PID_1001&MI_00  →  USB 串行设备 (COM16)      ← 数据/烧录口（CDC）
USB\VID_303A&PID_1001&MI_02  →  USB JTAG/serial debug unit ← 调试口
USB Composite Device 序列号：B8:1F:3F:C8:25:24
```

即 **一块板子出两个口**：`COM16` 走 CDC 串口，另一个是 USB-JTAG（可用于 OpenOCD 调试）。

USB mode:           USB-Serial/JTAG

## 4. 待确认 / 注意事项

- 引脚级定义（LCD 的 SCK/MOSI/CS/DC/RST/BL、摄像头 DVP 脚、I2C 触摸）以微雪官方 wiki 的引脚表为准；
  固件里只保留了 `SPI_MASTER_*`、`SDMMC_*`、`I2C_MASTER_*` 这类常量名，数值已编译进代码，不便于直接读出。
- 刷新固件前务必先整片备份：`dump\full_flash.bin`（命令见 README）。
- 屏幕上电前先确认 FPC 方向与锁扣到位，插反可能损坏背光/驱动。
- 摄像头与屏幕共用 FPC 座区，插拔时断电操作。
