# 中文显示方案：自制点阵字库

## 为什么不用现成字体

Arduino_GFX 只有 ASCII 点阵字体，带不了 CJK；把整个 TTF 塞进去更不现实（几 MB，还要跑解析）。
所以直接把需要的字**预先渲染成 1-bit 点阵**编进 flash，运行期只做查表 + 画横线。

## 生成

```powershell
.\.venv\Scripts\python.exe scripts\gen_cjk_font.py --size 16     # 小字（页脚/页码）
.\.venv\Scripts\python.exe scripts\gen_cjk_font.py --size 24     # 大字（标题/正文）
.\.venv\Scripts\python.exe scripts\gen_cjk_font.py --size 24 --font simhei
```

- 字表 = ASCII 0x20–0x7E + GB2312 全可解码字符（符号区 `0xA1A1–0xA9FE` + 汉字区 `0xB0A1–0xF7FE`）
- 字符数固定 **7540**（ASCII 95 + GB2312 7445）
- 产物大小：16px → `data/cjk16.bin` **301,612 B**；24px → `data/cjk24.bin` **603,212 B**
- 字体来源优先级：宋体（simsun）在 16px 下有专门的点阵化设计，笔画最清楚；雅黑/等线在小字号会糊；24px 下宋体与黑体都可用，黑体笔画更粗、远看更清楚

## 二进制格式

```text
magic   4B    "CJKF"
glyph_w u16   字宽（16 或 24）
glyph_h u16   字高（16 或 24）
count   u32   字符数
records count × (8 + ceil(glyph_w/8) × glyph_h) B
        ├ cp      u32    Unicode 码点（升序，供二分）
        ├ advance u8     推进宽度（像素；ASCII 是比例宽度）
        ├ pad     3B
        └ bitmap  rows×row_bytes   每行 ceil(w/8) 字节，高位在左
```

| 字号 | 行字节 | 单字记录 | 整块 |
|---|---|---|---|
| 16 | 2 | 40 B | 301,612 B（295 KB） |
| 24 | 3 | 80 B | 603,212 B（589 KB） |

两块都通过 `board_build.embed_files` 编进 flash，运行期符号
`_binary_data_cjk16_bin_start/end`、`_binary_data_cjk24_bin_start/end`。

## 设备端绘制

`src/cjk.cpp`：

1. `cjk_next()` 解 UTF-8，拿到码点
2. 在记录区做二分查找（记录定长，直接算偏移）
3. 逐行取 `row_bytes` 字节位图，把连续置位的像素合并成 `drawFastHLine` 一次画一段
4. 光标前进 `advance` 像素

两套字库共用一个 `struct Font`，`cjk_draw(..., CjkSize sz)` 选字号：
`CJK_S`（16px）用于页脚/页码，`CJK_L`（24px，默认）用于标题与正文。

代价：24px 一个汉字 24 行 × 最多 4 段横线 ≈ 96 次 `drawFastHLine`。
320×240 一屏 6 行 × 13 字 ≈ 78 个汉字，约 7500 次调用，整屏刷新在几十毫秒量级，
BLE 推送时感觉不到延迟（实测一次 `T` 指令后屏幕立刻更新）。

## 版式（24px 正文）

| 项 | 值 |
|---|---|
| 标题条高 | 34 px（标题 24px 居中，右侧页码 16px） |
| 正文起点 | y = 44 |
| 正文行距 | 28 px，最多 6 行（末行底部 208 < 页脚线 212） |
| 每行汉字 | 13 个（24px，边距 8px） |
| 页脚 | 分隔线 y=212，文字 y=216（16px） |

离线预览（不连板子，直接读字库渲染）：`scripts/preview_ui.py` → `docs/img/票据屏-预览.png`。

## 换字号 / 换风格

`gen_cjk_font.py` 的 `--size` 支持任意 12–32（行字节自动算）。改字号要同步改 `ui.cpp` 里的
`TITLE_H / BODY_Y / BODY_LH / BODY_LINES`，否则会溢出或留白。

代价参照：32px 单字 136 B × 7540 ≈ 1.03 MB，加上现有两套会超过 3 MB app 分区，
真要大字只能砍字符集（只留汉字区）或去掉小字号那套。

## 已知缺字

- 半角 `¥`（U+00A5）不在 GB2312，显示为空白；用全角 `￥`（U+FFE5）
- Emoji 一律缺字（显示空白），票据内容用不到
- 生僻字（GB2312 以外）缺字，例如部分人名用字
