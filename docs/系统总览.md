# 系统总览（截至 2026-11-02，固件 0.4.12 / App 0.6.8）

一句话：**一块 ESP32-S3 做成"桌面百宝箱"**——屏幕常显票据/信息，手机通过 BLE 推文字与图片，
另有原生系统信息页和照相模式（MJPEG 网页 + 拍照存卡 + 卡内相册）。

---

## 1. 硬件

| 项目 | 参数 |
|---|---|
| 板子 | Waveshare ESP32-S3-LCD-2（V2 原理图） |
| 芯片 | ESP32-S3 rev v0.2，240 MHz，8 MB OPI PSRAM，16 MB QIO Flash |
| 屏幕 | ST7789T3，240×320 竖屏物理，代码按 320×240 横屏（`setRotation(1)`）；**必须 INVON 才是黑底白字**；无触摸 |
| 摄像头 | OV5640（DVP 直连），640×480 JPEG 取帧 |
| 存储 | TF 卡 32 GB（SDHC），与 LCD 共用 FSPI（SCK39/MOSI38），CS41 |
| IMU | QMI8658A（加速度 ±4g、陀螺仪 ±2048 dps），I2C SDA48/SCL47 |
| 其它 | QMI8658 敲击中断引脚与 LCD TE 共用 GPIO3 → 用 25 ms 轮询代替中断 |
| 串口 | 原生 USB-CDC，COM16（打开会复位，且抓不到日志，调试优先用 HTTP） |
| 网络 | Wi-Fi STA `192.168.88.32`，mDNS `esp32note.local`；BLE 名 `ESP32-NOTE` |

**引脚占用**（详见 `docs/引脚定义.md`）：摄像头 16 个、LCD/TF 共用 9 个、电池/充电/UART/USB 6 个，
**唯一自由扩展口是 I2C（GPIO47/48）**。

## 3. 固件架构（notepad，单固件三模式）

```
setup(): ui_begin → cjk_init → 欢迎页 → notes_begin → qmi_begin → power_begin
         → 队列 → ble_begin → wifi_begin → 等满 2.5s → 系统信息页
         → 挂 TF 卡（只刷新文件系统，不再画屏）
loop():  power_tick() → 翻页/唤醒判定 → 串口指令 → BLE 队列执行
         → 摄像头推流（仅 cam 模式）→ 系统页 3 秒自动刷新
```

| 模式 | 触发 | 屏幕 | 手机端 |
|---|---|---|---|
| `note`（默认） | `MODE note` | 票据/图片 + 页脚状态 | 票据屏：文字、两步发图、翻页 |
| `sys` | `MODE sys` | 系统信息页（10 行） | 原生系统页：读 `SYS`、切页、反显 |
| `cam` | `MODE cam` | 地址页 + 帧率 | WebView 打开 `:8080` |

| 模块 | 行数 | 职责 |
|---|---|---|
| `main.cpp` | 805 | 模式机、BLE 指令分发、80 端口 httpd、OTA、串口指令 |
| `cam.cpp/.h` | 443 | 摄像头初始化、MJPEG 推流、8080 极简 HTTP、相册端点、网页 |
| `notes.cpp/.h` | 461 | 文本条目（8 条）+ 图片条目（RLE/1bpp）+ 照片列表/删除 + FFat/SD 双后端 |
| `ui.cpp/.h` | 378 | ST7789 版式（标题/正文/页脚）、欢迎页、系统页、1bpp 位图绘制 |
| `cjk.cpp/.h` | 166 | 16/24 px 点阵字库解析与绘制（码点二分 + 行合并） |
| `power.cpp/.h` | 299 | 敲击唤醒、甩动/翻牌手势、熄屏计时 |
| `qmi8658.cpp/.h` | 145 | IMU 驱动（加速度 + 陀螺仪） |

**显示版式**：标题条 34 px（`cjk_draw_scale` 可放大 2 倍到 48 px）、正文 6 行×28 px、页脚 28 px
（左：蓝牙已连/广播；中：常亮/60s 熄屏；右：页码）。字库 16 px 301,612 B、24 px 603,212 B，
共 7540 字（ASCII 95 + GB2312 7445），编译期 `board_build.embed_files` 嵌入。

## 4. BLE 协议（NUS，一行一条，`\n` 结尾，回执走 TX notify）

服务 `6E400001-B5A3-F393-E0A9-E50E24DCCA9E`，RX(`…0002`, write)、TX(`…0003`, notify)。MTU 协商到 517。

| 指令 | 作用 | 回执 |
|---|---|---|
| `V` | 版本 | `OK V 0.4.12` |
| `T 标题\|行1\|行2…` | 新增文本条目 | `OK T <id> <总数>` |
| `I <w> <h>` | 开始收图（w≤320，h≤212） | `OK I START WxH` |
| `A <base64>` | 图片 RLE 数据分片 | `OK A <累计字节>` |
| `E` | 结束收图 | `OK E <id> <rle字节> <位图FNV32>` |
| `Z` | 放弃收图 | `OK Z` |
| `L` / `P <id>` / `N` / `R` / `D <id>` / `C` | 列表 / 定位 / 下一条 / 上一条 / 删除 / 清空 | `OK L n`、`OK P i`、`OK D`、`OK C` |
| `B <0-100>` | 背光 | `OK B <pct>` |
| `S <0\|1>` | 熄屏 / 亮屏 | `OK S <n>` |
| `O <秒>` | 熄屏超时（0=常亮） | `OK O <n>` |
| `A` | 读加速度 | `OK A x y z` |
| `G` | 读加速度+陀螺仪 | `OK G ax ay az \| gx gy gz` |
| `Q` | 手势统计 | `OK Q <次> <角度> <轴> \| now <dps> peak <dps> \| k<符号>` |
| `M` | 探卡 | `OK M <类型> <MB> w=<0\|1>` |
| `K <1\|-1\|t>` | 翻页方向符号（存 NVS） | `OK K <n>` |
| `MODE sys\|note\|cam` | 切模式 | `OK MODE <名字>` |
| `INV <0\|1>` | 反显（存 NVS） | `OK INV <n>` |
| `SYS` | 系统快照 | `OK SYS ver=… mode=… tf=…MB bat=…V temp=…C heap=…KB …` |

**手势**：`power.cpp` 用加速度判「翻牌」（水平平举 → 翻向右侧 90° 回位 = 下一条，左侧 = 上一条），
用陀螺仪判甩动（统计用）；熄屏时敲击（`TAP_THRESHOLD 0.75g`）唤醒并顺带翻页。

## 5. HTTP 服务

**80 端口（httpd）**：`/`、`/status.json`、`/ota`、`/update`（OTA 走 `Update.h`，写另一半 app 槽）。
> ⚠️ 目前该服务不响应请求（8080 正常），OTA 暂时不可用，已列为明天第一项。

**8080 端口（手写极简 HTTP，一请求一连接）**：

| 端点 | 作用 |
|---|---|
| `GET /`（含 `/?t=`） | 照相控制页（实时流 + 拍照 + 看当前帧 + 卡内照片） |
| `GET /stream` | MJPEG 流（单观看端） |
| `GET /capture` | 单帧 JPEG |
| `GET /shot` | 拍照存卡 → `/camNNNN.jpg` |
| `GET /list` | 卡内照片 JSON |
| `GET /photo?n=` | 下载单张（`Content-Disposition`） |
| `GET /del?n=` | 删除单张 |
| `GET /status.json` | 状态（ver/up/heap/wifi/rssi/ble/mtu/notes/cur/bl/ot/imu/idle/mode/cam/sd/ifs/isz/bk/rx/lc/lr…） |
| `GET /reboot` | 重启 |

## 6. 存储

- **图片条目**：1-bit 位图（`stride=(w+7)/8`，MSB 在左，1=白）+ RLE（`[count][0x00|0xFF]`），上限 3 张，
  存 PSRAM/内部 RAM，落盘 `/<id>.rle` + `/imgs.txt` 索引。
- **照片**：`/camNNNN.jpg`，直接存 TF 卡根目录。
- **后端选择**：`img_fs()` 返回 SD 或内部 FFat（10 MB），挂卡成功且有写权限才用卡，否则回落 FFat 并自动迁移一次。

## 7. 分区与烧录（16 MB）

```
nvs      0x9000    0x5000
otadata  0xe000    0x2000
app0     0x10000   0x400000      # 4 MB（三模式合并后 2.0 MB，留足余量）
app1     0x410000  0x400000
ffat     0x810000  0x7e0000      # ~7.9 MB
coredump 0xff0000  0x10000
```

烧录（双槽写、先清 otadata，约 6 秒）：

```powershell
python -m esptool -p COM16 -b 921600 erase-region 0xe000 0x2000
python -m esptool -p COM16 -b 921600 write-flash 0x10000 firmware.bin 0x410000 firmware.bin
```

编译要在 **ASCII 路径的 junction** 里跑（中文路径会让 ld 打不开 map 文件）：
`mklink /J C:\esp32np "E:\ESP32开发\firmware\notepad"`，然后 `cd C:\esp32np; platformio run`。

## 10. 已知限制与坑（写进这里免得再踩）

1. **挂 TF 卡之后不要写显存**：`s_sd_spi.begin()` 重配 FSPI 后列地址偏移 → 屏幕「左黑右白」。开机挂卡只刷新文件系统。
2. **这颗 ST7789 必须 INVON**（`invertDisplay(true)`），否则是白底黑字；设置存 NVS。
3. **lwIP 只有 10 个 socket**：高频取图会把连接池吃干 → 照相页用单观看端 + 一发即关。
4. **中文路径编译失败**：`E:\ESP32开发` 下 ld 打不开 map，必须走 `C:\esp32np` junction。
5. **`pio run -t upload` 在 USB-CDC 上不可靠**：切波特率后 `No serial data received`，用 esptool 直写。
6. **换固件必须双槽写 + 清 otadata**，否则 OTA 残留的 otadata 会引导到上一个固件。
7. **摄像头"连不上"多半是排线接触**：`esp_camera_init()` 失败会让整机复位（表现成 Wi-Fi/BLE 全掉）。
8. **BLE 连上就停广播**：手机占用时 PC 端 `ble_test.py` 扫不到设备；调试走串口或 HTTP。
9. **80 端口 httpd 目前不响应**（待修），OTA 暂时不能用。
10. **电池电压分压系数未校准**：`bat=2.73V` 与实测 3.87V 不符，等电池到位后标定。
